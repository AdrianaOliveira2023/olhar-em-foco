# Olhar em Foco — Landing Page Demonstrativa

## Sobre o projeto

Landing page criada por Adriana como parte do meu processo de aprendizagem em desenvolvimento web.

O projeto apresenta uma proposta fictícia de divulgação de um encontro de fotografia com celular, inspirada na atividade profissional de um amigo fotógrafo.

**Importante:** este é um projeto demonstrativo. Não representa um curso ou evento real e não possui inscrições abertas.

## Tecnologias utilizadas

- HTML5
- SCSS
- CSS3
- JavaScript
- Supabase

## Estrutura do projeto

- `index.html` — estrutura e conteúdo da página.
- `style.scss` — estilos editáveis do projeto.
- `style.css` — CSS compilado para o navegador.
- `script.js` — interações e funcionalidades da página.
- `supabase.js` — configuração da integração com Supabase.
- `imagens/` — fotografias utilizadas no projeto.

## Fotografias

Todas as fotografias utilizadas no projeto são autorais de Adriana.

## Desenvolvimento

Projeto desenvolvido por Adriana, com uso de inteligência artificial (ChatGPT/OpenAI) como principal ferramenta de apoio à criação da estrutura, elaboração do código e revisão da página.

O processo também envolveu orientações, escolhas, personalizações, ajustes e testes realizados durante a aprendizagem.

As decisões, adaptações, personalizações e testes fizeram parte do processo de aprendizagem e desenvolvimento.

## Objetivos de aprendizagem

- Estruturação de páginas com HTML.
- Estilização e organização com SCSS e CSS.
- Desenvolvimento de interações com JavaScript.
- Criação de layouts responsivos.
- Experimentação com formulários e integração com Supabase.
- Organização e publicação de projetos no GitHub.
